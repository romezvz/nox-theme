# Changelog

All notable changes to NOX will be documented in this file.

## [1.0.2]

### Changed

- Refined the Marketplace display name to **NOX — Graphite**.
- Updated project documentation and branding consistency.
- Improved installation instructions for all distribution channels.

### Added

- Dynamic Visual Studio Marketplace badges.
- Direct Marketplace installation links.
- Command-line installation instructions.
- Marketplace rating and feedback links.

### Unchanged

- Graphite interface and color palette.
- Syntax highlighting and italic styles.
- Extension identifier and theme label.

## [1.0.1]

### Added

- Official Visual Studio Marketplace distribution.
- Registered publisher: `romezvz`.
- Marketplace gallery banner.

### Changed

- Updated extension identifier to `romezvz.nox-graphite`.
- Updated extension display name to **NOX — Graphite Theme**.
- Refined extension packaging.

## [1.0.0]

### Added

- Initial stable release of NOX.
- Refined graphite workbench interface.
- Original Moonlight Italic syntax highlighting.
- Neutral interface typography.
- Minimal editor tabs and subtle borders.
- Balanced editor, sidebar and terminal backgrounds.
- Essential monogram and visual identity.
- Optional visual settings preset.
- Official documentation and theme previews.
- GitHub distribution through VSIX packages.
- MIT License.
